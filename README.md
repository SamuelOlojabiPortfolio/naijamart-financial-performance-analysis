# 🛒 NaijaMart Retail Financial Performance Analysis

## 📊 Project Overview

**NaijaMart Retail Financial Performance Analysis** is a Power BI project focused on analyzing the sales and financial performance of a fictional Nigerian retail business.

Using a **10,000-row retail transaction dataset**, I transformed transactional data into an interactive dashboard to understand **revenue, sales, costs, profit, discounts, products, regions, customers and salesperson performance**.

The goal was to turn raw business data into clear insights that could support **performance monitoring and better decision-making**.


---

## 🎯 Business Questions

The analysis focuses on questions such as:

- How is NaijaMart performing in terms of revenue and profit?
- Which products and categories generate the most sales?
- Which regions, states and stores perform best?
- Which products and categories are most profitable?
- How do costs and discounts affect profitability?
- Which customers and salespeople contribute the most to revenue?
